# Prompts de imágenes para las cartas

Estas 100 cartas tienen ahora una imagen provisional en pixel art hecha por código. Cada prompt sirve para generar la definitiva con tu IA de imágenes, en el mismo estilo que el resto de cartas.

1. Genera la imagen con el prompt (en inglés funcionan mejor).
2. Recórtala a **423x308** y súbela a Cloudinary.
3. Pon la URL en `text.image` del Excel y pásamela: la cambio en la BD.

Si alguna no queda bien, añade al final del prompt lo que quieras cambiar.
